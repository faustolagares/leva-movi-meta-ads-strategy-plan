# public/images

Imagens usadas pela página `index.html`.

## Arquivos esperados

- **`itaberai-leva-movi.webp`** — imagem da hero (topo da página). Referenciada em
  `index.html` como `public/images/itaberai-leva-movi.webp`.
  Formato: `.webp`. Proporção recomendada: paisagem/quadrada (a hero usa layout de
  duas colunas; a imagem ocupa a coluna direita e escala em largura).

> Coloque o arquivo `.webp` real nesta pasta com exatamente esse nome para que a
> hero exiba a imagem.
